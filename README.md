# Paperflip · 만화 컬렉션과 책 뷰어

만화 이미지를 한 권으로 묶어 저장하고, 컬렉션에서 골라 책처럼 넘겨 읽는 웹 프로젝트입니다. **뷰어 · 컬렉션 · 파일추가** 세 탭으로 구성했습니다. 기본 만화나 첨부 이미지는 포함하지 않습니다.

## 실행과 종료

Windows에서는 **실행하기.cmd**를 더블클릭합니다. 로컬 서버와 브라우저가 열립니다. 이 PC의 Codex에 포함된 Node.js도 자동으로 찾으므로 별도 패키지 설치는 필요 없습니다.

종료할 때는 **중지하기.cmd**를 더블클릭합니다. 브라우저를 닫아도 로컬 서버는 계속 실행됩니다.

다른 환경에서는 Node.js 18 이상으로 실행합니다.

~~~sh
node server.mjs
~~~

브라우저 주소는 http://127.0.0.1:8787 입니다. 포트 변경은 아래처럼 합니다. 터미널로 실행한 서버는 Ctrl+C로 중지할 수 있습니다.

~~~sh
node server.mjs --port 8790
~~~

## 비밀번호로 입장

처음 접속하면 **내 서재의 비밀번호 만들기** 화면이 열립니다. 직접 비밀번호를 8~128자로 정하고 확인 입력까지 마친 뒤 **비밀번호 정하고 시작하기**를 누릅니다. 설정 후에는 접속 시 비밀번호로 로그인합니다. 비밀번호를 채팅에 전달할 필요는 없습니다.

사용을 마친 뒤 오른쪽 위 **잠그기**를 누르면 입장 화면으로 돌아갑니다. 저장한 컬렉션과 읽던 위치는 유지됩니다. 로그인 세션은 최대 8시간이며, 서버를 다시 실행하면 다시 로그인해야 합니다. 여러 번 틀리면 1분 동안 다시 입력할 수 없습니다.

비밀번호 원문은 저장하지 않고, 무작위 salt와 scrypt 해시를 프로젝트의 **.private/password.json**에 저장합니다. 이 폴더는 Git 관리와 웹 파일 제공에서 제외합니다. 새 서버로 프로젝트를 옮겨 처음 실행하면 비밀번호를 다시 정할 수 있습니다. .private 폴더에 이미 설정 파일이 있으면 다른 비밀번호로 초기 설정을 덮어쓸 수 없습니다.

서버에서 로그인 세션을 확인해 화면·스크립트·정적 파일 요청을 제한합니다. 로그인 쿠키는 HttpOnly와 SameSite=Strict를 사용하며, 잠그기 시 서버에서 세션을 무효화합니다. 비밀번호 잠금은 사이트 입장 인증이며, 브라우저에 저장된 이미지 사본을 암호화하는 기능은 아닙니다. 현재 서버는 이 PC에서만 열립니다. 인터넷에 배포할 때는 HTTPS와 배포 서버의 인증 구성을 적용해야 합니다.

## 파일추가 → 컬렉션 → 뷰어

1. **파일추가** 탭에서 이미지 여러 장 또는 ZIP·CBZ 한 개를 선택하거나 화면에 끌어 놓습니다. 압축 파일은 안의 이미지를 자동으로 추출합니다.
2. 만화 제목과 읽는 방향을 정합니다. 같은 작품의 여러 권은 시리즈명과 권 번호를 입력하고, 원하는 태그를 쉼표로 구분해 붙입니다.
3. 미리보기 목록에서 페이지 순서를 확인합니다. 처음에는 파일명 숫자 순서로 정렬하며, 위·아래 버튼으로 순서를 바꾸고 × 버튼으로 이미지를 제외할 수 있습니다. 첫 이미지가 표지가 됩니다.
4. **컬렉션에 저장**을 누릅니다. 현재 목록의 이미지들을 한 권으로 묶어 저장합니다.
5. **컬렉션**에서 표지나 읽기 버튼을 누르면 **뷰어**로 이동합니다.
6. 책 넘김 모드에서는 책장 바깥쪽을 마우스로 잡아 책등을 지나 놓으면 넘어갑니다. 조금만 당겼다 놓으면 돌아옵니다. 보기 모드, 이전·다음 버튼, 방향키, 확대, 책만 전체화면도 지원합니다.

새 이미지를 추가하면 기존 준비 목록과 합쳐 파일명 순서로 다시 정렬합니다. 같은 파일명은 새 파일로 교체합니다. ZIP·CBZ는 한 개를 한 권으로 준비하므로 준비 목록이 비어 있을 때 한 개씩 추가합니다. 현재 책을 저장하거나 목록을 비운 뒤 다음 압축 파일을 추가합니다. 저장하지 않은 준비 목록은 새로고침하면 비워집니다.

## ZIP·CBZ 불러오기

일반 ZIP 형식의 ZIP·CBZ에서 JPG, PNG, WebP, GIF, AVIF, BMP를 추출합니다. 하위 폴더의 이미지도 경로와 파일명의 숫자 순서로 정렬하며, 미리보기 목록에서 순서를 바꿀 수 있습니다. ComicInfo.xml, 숨김 파일, macOS 보조 파일 등은 제외합니다. 압축 파일명은 만화 제목의 초깃값으로 사용합니다.

무압축(Store)과 일반 Deflate 압축을 지원합니다. 손상되거나 암호화된 파일, 분할 ZIP, ZIP64, 다른 압축 방식은 안내 후 제외합니다. 압축 파일은 256 MB 이하, 추출한 이미지는 한 장 64 MB·전체 512 MB·최대 3,000장입니다. 파일 크기와 CRC를 확인해 손상된 압축 데이터를 저장하지 않습니다. 압축 해제는 브라우저에서 수행하며 추가 서버나 외부 라이브러리는 필요 없습니다. Deflate 압축에는 브라우저의 DecompressionStream('deflate-raw') 지원이 필요합니다.

## 시리즈와 권 관리

파일추가에서 시리즈명과 1~9999 사이의 권 번호를 선택 입력합니다. 시리즈명만 넣고 권 번호는 나중에 지정할 수도 있습니다. 시리즈명과 권 번호를 모두 비우면 단권으로 저장합니다. 기존 만화에는 컬렉션의 **정보·태그 편집** 버튼으로 정보를 추가하거나 변경할 수 있습니다.

컬렉션은 같은 시리즈를 묶고 권 번호 순으로 보여 줍니다. 시리즈 선택 메뉴로 작품 하나 또는 단권만 골라 볼 수 있으며 제목과 시리즈명으로 검색합니다. 권 번호를 지정하지 않은 책은 같은 시리즈의 마지막에 정렬합니다. 뷰어의 **이전 권·다음 권**으로 저장된 권 순서에 따라 이동합니다. 휴지통의 책은 권 이동에서 제외합니다.

## 만화별 태그와 검색

파일추가의 **태그** 입력칸 또는 컬렉션 카드의 **정보·태그 편집**에서 `액션, 판타지, 완결`처럼 쉼표로 구분해 입력합니다. 태그를 지우고 저장하면 해당 태그가 제거됩니다. 한 만화에 최대 20개, 태그 하나는 40자까지 붙일 수 있습니다. 앞뒤 공백과 중복 태그는 정리하며 영문 대소문자가 다른 태그도 하나로 취급합니다. 저장한 태그는 카드에 표시되고 새로고침 후에도 유지됩니다. 기존 컬렉션을 다시 등록할 필요는 없습니다.

컬렉션의 **태그로 골라 보기**에서 체크박스로 태그를 선택합니다. 여러 개를 체크하면 선택한 태그 중 하나라도 붙은 만화가 표시됩니다. 체크하지 않으면 태그 없는 만화도 포함해 전체를 보여 줍니다. 숫자는 현재 컬렉션 또는 휴지통에서 그 태그가 붙은 만화 수입니다. **태그 선택 해제**로 체크만 초기화할 수 있습니다.

**제목·시리즈 검색**, 시리즈 선택과 태그 체크는 동시에 적용됩니다. 예를 들어 `우주`를 검색하고 `완결`을 체크하면 제목이나 시리즈명에 우주가 포함되고 완결 태그가 붙은 만화를 보여 줍니다. 검색 결과에는 표시한 권 수를 안내합니다. 휴지통으로 이동해도 태그는 보존되고 복원 후 다시 사용할 수 있습니다.

## 보기 모드와 책만 전체화면

- **책 넘김:** 종이 접힘·그림자와 마우스 드래그로 책장을 넘깁니다. 표지를 펼친 뒤 두 페이지씩 봅니다.
- **한 페이지:** 한 장씩 크게 보고 이전·다음으로 이동합니다. 좁은 화면에서는 페이지를 화면 너비에 맞춰 보여 줍니다.
- **두 페이지:** 첫 페이지부터 두 장씩 나란히 봅니다. 오른쪽부터 읽으면 페이지 배치도 반대로 바뀝니다.
- **세로 스크롤:** 페이지를 위에서 아래로 이어 보고, 스크롤 위치에 따라 읽던 페이지를 저장합니다.

보기 모드와 읽던 페이지는 책마다 저장합니다. 모드를 바꿔도 현재 페이지가 포함된 화면을 엽니다. 두 페이지 모드와 책 넘김 모드에서는 같은 묶음의 앞 페이지를 기준으로 이어 읽습니다. 기존에 저장한 책도 다시 등록할 필요 없이 사용할 수 있습니다.

모든 모드에서 **←·→**로 이동합니다. 오른쪽부터 읽는 경우 **←**가 다음 페이지입니다. **↑·↓**, **PageUp·PageDown**은 읽는 방향에 관계없이 이전·다음으로 이동합니다. 입력칸·선택 메뉴·탭을 조작할 때는 페이지를 넘기지 않습니다.

**책만 전체화면**은 메뉴와 탭을 숨기고 현재 책만 보여 줍니다. 드래그와 방향키도 계속 사용할 수 있습니다. **Esc** 또는 오른쪽 위 **닫기**로 나옵니다. 전체화면을 지원하는 브라우저에서는 책 영역 자체를 전체화면으로 열며, 내장 브라우저 등에서 전체화면을 제한하면 브라우저 화면을 채우는 책 보기로 전환합니다.

## 컬렉션과 이어 읽기

- 제목 검색, 최근 추가순·최근 읽은순·제목순 정렬을 지원합니다.
- 만화 제목을 바꿔도 페이지와 읽던 위치는 유지합니다.
- 페이지를 넘기거나 보기 모드·읽는 방향을 바꾸면 책마다 읽던 위치와 설정을 자동 저장합니다.
- 새로고침하거나 브라우저를 다시 열어도 저장한 만화의 이미지를 다시 선택할 필요가 없습니다.
- **휴지통**으로 옮긴 만화는 컬렉션에서 숨겨지며, 휴지통에서 복원할 수 있습니다. 원본 파일은 수정하거나 삭제하지 않습니다.
- 뷰어 탭을 직접 열면 마지막으로 선택했던 책을 다시 펼칩니다.

## 저장 위치와 범위

제목, 태그, 시리즈와 권 번호, 표지, 원본 이미지 사본, 페이지 순서, 보기 모드, 읽는 방향, 읽던 위치는 브라우저의 **IndexedDB**에 저장합니다. DB 이름은 paperflip-library-v1이며 books와 pages 저장소를 사용합니다. 마지막으로 선택한 책의 ID만 localStorage에 저장합니다.

이미지를 서버로 업로드하거나 프로젝트의 assets 폴더에 복사하지 않습니다. 컬렉션은 같은 PC의 같은 브라우저 프로필과 같은 사이트 주소에서 유지됩니다. 다른 브라우저, 주소 또는 포트에는 자동으로 공유되지 않습니다. 서버를 종료해도 컬렉션은 남지만 사이트 데이터를 지우면 사라집니다. 시크릿 모드의 데이터는 해당 세션 종료 시 사라질 수 있습니다. 계정·클라우드 동기화·백업 내보내기는 현재 없습니다.

컬렉션 목록은 작은 표지를 사용합니다. 원본 이미지 해독은 선택한 책을 열 때 수행하며, 책을 바꾸면 이전 책의 이미지 객체를 해제합니다. 매우 긴 책의 페이지별 지연 로딩은 추후 추가할 수 있습니다. 저장 공간이 부족하면 저장 실패를 알리고 파일추가 목록을 유지합니다.

지원 파일은 JPG, PNG, WebP, GIF, AVIF, BMP와 일반 ZIP·CBZ이며 실제 이미지 읽기 가능 여부는 브라우저에 따릅니다. 손상된 이미지는 파일추가 단계에서 제외합니다. PDF, RAR, CBR은 현재 지원하지 않습니다.

## 프로젝트 구조와 통합

~~~text
comic-book-reader/
  index.html               세 탭과 화면 구조
  login.html               비밀번호 설정과 입장 화면
  auth.mjs                 비밀번호 해시, 로그인 세션, 재시도 제한
  src/
    app.js                 탭 이동, 파일 등록, 컬렉션과 뷰어 연결
    auth.js / auth.css     비밀번호 입장 화면 동작과 디자인
    access.js              세션 확인과 서재 잠그기
    book-store.js          책과 이미지의 영구 저장, 읽기 위치, 휴지통
    archive.js             ZIP·CBZ 이미지 추출과 파일 검증
    book-reader.js         네 가지 보기 모드와 페이지 이동
    reading-state.js       읽던 페이지 변환과 시리즈·권 정보
    collection-filter.js   태그 정리와 제목·시리즈·태그 필터
    flip-book.js           책 그리기, 드래그, 그림자, 넘김 애니메이션
    geometry.js            페이지 순서와 종이 접힘 계산
    styles.css             화면 디자인과 반응형 배치
  assets/.gitkeep          비어 있는 정적 파일 폴더 유지
  tests/                   압축·보기 모드·접힘·비밀번호·서버 검증
  server.mjs               단독 실행용 로컬 정적 파일 서버
  start.ps1 / stop.ps1     Windows 실행·종료 보조
  실행하기.cmd / 중지하기.cmd
  package.json
  README.md
  .gitignore
~~~

외부 라이브러리와 빌드 단계 없이 HTML, CSS, JavaScript로 구성했습니다. 화면이나 기능을 고친 뒤 브라우저를 새로고침하면 반영됩니다. 서버 코드를 수정한 경우 서버를 다시 시작합니다. index.html은 서버를 통해 열어 주세요.

다른 프로젝트에 통합할 때는 index.html의 화면 구조와 src 폴더를 기존 서버에서 제공하도록 연결합니다. server.mjs와 Windows 실행 보조 파일은 단독 실행용이므로 통합 서버에 추가할 필요가 없습니다. 저장 동작을 서버 API로 바꾸려면 book-store.js의 listBooks, getPages, createBook, updateBook 인터페이스를 해당 저장 방식으로 구현하면 됩니다. 사이트 주소가 바뀌면 브라우저의 기존 컬렉션은 자동 이동하지 않습니다.

비밀번호 기능도 통합하려면 기존 서버의 로그인 체계에 연결하거나 auth.mjs의 해시·세션 검사와 /api/auth/ 경로를 기존 서버에서 구현해야 합니다. 화면 파일만 옮기는 경우 비밀번호 인증이 자동으로 추가되는 것은 아닙니다. 비밀번호 확인은 통합 후에도 서버에서 수행합니다.

## 검증

~~~sh
node --test
node --check src/app.js
node --check src/book-store.js
node --check src/flip-book.js
~~~

패키지 관리자가 있다면 npm start, npm test, npm run check도 사용할 수 있습니다. 별도 의존성 설치는 필요 없습니다.

컬렉션 저장, 태그 편집·체크박스 필터와 검색, ZIP·CBZ 추출과 페이지 순서, 시리즈 편집·권 이동, 네 가지 보기 모드, 새로고침 후 이어 읽기, 방향키와 전체화면 드래그, 제목 변경, 휴지통 복원과 모바일 배치는 실제 브라우저에서 확인합니다. 로컬 서버는 127.0.0.1에서만 열립니다.
